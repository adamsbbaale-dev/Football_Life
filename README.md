# Football Life

A playable Godot starter prototype inspired by the idea of a modern football-life city sim with roaming, apartment life, shops, squad building, match simulation, relationships, and transfer logic.

This project is intentionally built as a vertical slice: a playable foundation you can expand into a larger game using your Quantaruis Mega Building Kit assets and more advanced systems.

## Included
- Apartment home base
- City roaming scene
- Stadium scene with simple match flow
- Player movement and outfit switching
- Shops for clothes, car upgrade, and health restoration
- NPC relationship system
- Transfer interest logic by rating
- Match story log summarizing anthem, walkout, and trophy scene
- Save-ready player data structure

## How to run
1. Open the project in Godot 4.
2. Press F5 or Run Project.
3. Use the on-screen buttons to travel between apartment, city, and stadium.

## Controls
- WASD or arrow keys to move the player in city mode.
- Buttons in the UI for travel, shops, and match actions.

## Notes
- This is a prototype foundation, not a full commercial game.
- Quantaruis Mega Building Kit assets can be imported later into `assets/quantaruis/` and swapped into the city/stadium building scenes.
- The project uses simple geometric placeholders so it works without external art.
